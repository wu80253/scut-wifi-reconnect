# scut-student 校园网自动重连

在 Windows 上定时检查 `scut-student` 的连接，按需重新连接 Wi-Fi，并通过 Microsoft Edge 提交校园网登录。克隆仓库后，可以直接运行同目录的 `校园网设置.exe`。

## 首次设置

1. 在宿舍电脑上，从 Windows 的 Wi-Fi 菜单手动连接一次 `scut-student`，让 Windows 保存连接配置。
2. 双击 **校园网设置.exe**。认证地址已填 `s.scut.edu.cn` 的入口，填写你的宿舍上网账号和密码，点击 **保存设置**。如果你有学校提供的完整认证网址，也可以填入认证页地址栏。
3. 点击 **立即检查** 查看结果。已经能上网时会显示「外网探测通过」。要验证自动登录，等下一次 Wi-Fi 已连但网页版要求登录时，再点一次「立即检查」。
4. 点击 **启用自动重连** 后可以关闭窗口。停用时重新打开窗口，点击 **暂停自动重连**。

## 运行方式

- 后台任务每分钟检查一次，检查完成后退出。检测到 `scut-student` 在附近时，使用保存的 Windows Wi-Fi 配置恢复连接。连接后检查外网，按需启动临时 Edge 窗口执行网页登录。
- 每天 00:00–06:00 暂停自动提交登录。06:00 恢复检查和认证。一次自动认证尝试后，至少间隔 5 分钟才再次尝试。手动点击「立即检查」可以即时重试。
- Windows 用户登录后，锁屏状态可运行。睡眠或休眠时，等电脑唤醒后继续检查。要远程使用，宿舍电脑需保持开机和可运行状态。
- 账号和密码在本机保存，密码用当前 Windows 用户的系统密钥加密。最近一次检查结果保存在 `%LOCALAPPDATA%\ScutWifiHelper`。改密码时在设置窗口重新保存。
- 移动项目文件夹前，先暂停自动重连。移到新位置后双击入口，重新启用任务。

## 提示与验证

- 如果状态提示 Windows 限制读取 Wi-Fi，打开 **设置 → 隐私和安全性 → 位置**，检查是否允许桌面应用访问位置，再点「立即检查」。
- 如果连接探测收到 `s.scut.edu.cn` 的认证跳转，脚本优先用这次跳转的完整地址，保留页面需要的参数。已用模拟网页验证「登录/Login」按钮。实际校园网要求重新认证时，可从「立即检查」查看结果。
- 如页面要求验证码或其他选项，「立即检查」可能提示无法识别登录表单。网页实际使用的地址若与截图不同，可录入学校提供的完整网址。
- 若认证入口只提供 `http://`，网页登录仍按该站点原有协议通信。校园网有可用的 `https://` 入口时，优先填 HTTPS 地址。
- 验证远控时，锁定宿舍电脑，再用手机流量从外网连接。窗口里的外网探测结果只反映当前网络能否访问探测地址。

## 重新编译启动器

如果修改了 `Launcher.cs`，在项目目录打开 PowerShell，用 .NET Framework 的 C# 编译器生成启动程序。

```powershell
$compiler = Join-Path $env:SystemRoot 'Microsoft.NET\Framework\v4.0.30319\csc.exe'
& $compiler /nologo /codepage:65001 /target:winexe /platform:anycpu /optimize+ /reference:System.Windows.Forms.dll /out:校园网设置.exe Launcher.cs
```
